# Utility Functions

This folder contains utility functions for various operations.

## Files

### `export.js`
- **Purpose:** Export result data as PDF or CSV
- **Functions:**
  - `exportAsPDF(result)` - Export result as PDF file
  - `exportAsCSV(result)` - Export result as CSV file
- **Usage:** Can be imported when needed for result export functionality

## Import Examples

```javascript
import { exportAsPDF, exportAsCSV } from "@/lib/utils/export";
```
